# 支持平台

Glean (拾句) 专注于提供极致的视频播放沉浸感，目前官方支持三大平台：

| 平台 | 适配说明 | 字幕嗅探机制 |
| :--- | :--- | :--- |
| **夸克网盘网页版** (`pan.quark.cn`) | 独家深度适配在线播放器，支持中英双语、生肉自载与控制栏挂载 | 原生 `textTracks` 提取 + 动态 blob 拦截 |
| **YouTube** | 官方支持，自动适配新版与经典版 YouTube 播放器 | `/timedtext` JSON3 拦截 + ASR 滚动字幕去重 |
| **Bilibili** | 官方支持视频详情页播放器，控制条与侧栏风格统一 | 主世界网络拦截 + 原生控制栏挂载 |

---

## ☁️ 夸克网盘网页版使用技巧
1. 登录夸克网盘网页版并打开任意视频播放页面；
2. 插件会自动检测视频节点，并在原生播放器右侧挂载开关与设置入口；
3. 若视频内嵌有英文字幕，Glean 会自动激活并展示双语；
4. 若视频无字幕，可点击右侧面板中的【导入字幕】，直接拖入本地 `.srt` / `.vtt` / `.ass` 文件即可无缝学习！

## 🎬 YouTube 广告与跨集隔离
- **广告生命周期隔离**：播放贴片广告时，插件会自动暂存正片字幕，广告播放完毕后无缝还原正片台词与进度；
- **跨视频状态重置**：检测到换视频或切换集数时，自动清空上一集的台词缓存与 AI 精翻状态，杜绝数据串联。
