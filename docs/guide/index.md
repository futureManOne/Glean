# 项目简介

**Glean（拾句）** 是一款开源、免费、隐私优先的沉浸式双语视频学习浏览器扩展（Chrome Manifest V3）。

它把 **YouTube**、**Bilibili**、**夸克网盘网页版（`pan.quark.cn`）** 上的普通视频变成可点、可查、可跟读、可精翻的沉浸式语言学习现场。

---

## 核心设计哲学

1. **零画面干扰**：视频画面内部绝不渲染常驻的悬浮工具黑条，所有开关与设置无缝嵌入播放器底部的原生控制栏，随控制栏智能显隐。
2. **毫秒级播放感知**：无论何时快进快退，AI 精翻算法自动打断后台，1 秒内抢占精翻当前播放指针所在的句子。
3. **断网可用与隐私绝对安全**：内置 42,978 条高频词条与 94,108 条词形还原规则，离线也能秒级查词；数据仅存于浏览器本地 `chrome.storage.local`。
4. **完整的输入到输出闭环**：不仅解决“看懂”的问题，还通过单句循环重播（S/Z）与一键导出 Anki 牌组，彻底解决“记住”和“复习”的问题。
