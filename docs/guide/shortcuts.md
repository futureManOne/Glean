# 全键盘快捷键速查

为了保证高效学习，Glean (拾句) 支持全键盘无鼠标操作。

| 快捷键 | 功能 | 说明 |
| :---: | :--- | :--- |
| <kbd>A</kbd> | 上一句台词 | 跳转到上一句字幕的起始位置 |
| <kbd>D</kbd> | 下一句台词 | 跳转到下一句字幕的起始位置 |
| <kbd>S</kbd> | 重播当前句 | 立即从头重播当前台词（精听必备） |
| <kbd>Z</kbd> | 单句循环开关 | 开启/关闭当前句无限循环锁定 |
| <kbd>Space</kbd> | 播放 / 暂停 | 兼容视频原生播放与暂停 |
| <kbd>W</kbd> | 译文行显隐 | 快速显示或隐藏中文翻译行 |
| <kbd>V</kbd> | 字幕总开关 | 一键彻底隐藏或唤醒全部字幕层 |
| <kbd>C</kbd> | 字幕模式循环 | `双语` ➔ `混合` ➔ `外语` ➔ `译文` ➔ `隐藏` |
| <kbd>E</kbd> | 台词侧边栏开关 | 展开或收起右侧全文提词器面板 |
| <kbd>[</kbd> / <kbd>]</kbd> | 时间轴微调 | 每次前后微调 0.5 秒，解决字幕时间偏差 |

> 💡 **防冲突设计**：当焦点处于输入框（如视频评论区、搜索框）时，快捷键自动让位，绝不打扰正常打字；同时不会劫持 Ctrl/Cmd/Alt 组合键。
