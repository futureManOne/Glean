# 单词卡片与 CEFR 分级

Glean (拾句) 将视频中的每一句台词都转化为交互式的学习媒介。

---

## 逐词即查与欧标着色

- **分词引擎**：基于浏览器原生 `Intl.Segmenter`，准确切分每一个英文单词，每个单词都可独立点击；
- **CEFR 欧标分级**：自动将单词标记为 `A1` 到 `C2` 等级，并根据掌握程度显示不同的颜色；
- **离线词典**：内置 ECDICT 核心离线词库（42,978 词条 + 94,108 条词形还原），断网状态下也能秒出权威词义。

---

## ESL 深度例句教学体系

在单词卡片中，点击【拓展例句】选项卡，将触发三卡片教学：
1. **地道双语例句**：包含整句 TTS 朗读与高亮；
2. **📖 词义用法解析**：深度剖析该词在特定语境下的语体色彩、褒贬态度与说话人意图；
3. **🔍 语法结构解析**：拆解该词在句中的句法功能、主谓宾结构与固定搭配。
