# Anki 与讲义导出

不仅在观影时学，更要在观影后沉淀。Glean 提供了全方位的导出与复习闭环。

---

## 导出为 Anki 牌组 (.tsv)

在右侧台词侧边栏中，点击【导出】 -> 【Anki TSV】：
- **生词本导出**：导出已收藏的生词、音标、释义、例句与当前语境台词；
- **全片台词导出**：导出全片双语对齐句子，正面为英文原句 + 时间轴，背面为地道中文译文。

### 如何导入 Anki
1. 打开电脑端 Anki，点击菜单中的【文件】 -> 【导入】；
2. 选择下载的 `.tsv` 文件；
3. 分隔符选择“制表符 (Tab)”，按提示完成字段映射即可一键同步至手机！

---

## 全剧本文档导出

支持一键将整集台词导出为以下格式：
- **SRT / VTT**：标准外挂双语字幕文件；
- **Word / HTML**：排版优雅的双语讲义；
- **PDF 打印版**：自带时间戳与徽标，适合打印精读；
- **CSV / JSON**：结构化数据，方便程序员做二次加工。
