# 常见问题排查 (FAQ)

---

### Q1：视频没有字幕怎么办？
**答**：  
1. 请先确认视频播放器是否本身含有外挂字幕或内嵌字幕；  
2. 若确实没有在线字幕，可点击侧边栏的【导入字幕】，将本地已有的 `.srt` / `.vtt` / `.ass` / `.txt` 字幕文件拖入网页即可立即载入；  
3. 您也可以点击【加载演示字幕】先快速体验全部双语及词卡功能。

---

### Q2：AI 精翻一直失败或报错？
**答**：  
1. 请检查设置面板中的 `API Key` 是否正确填入，且账号是否有足够额度；  
2. 在设置中点击【保存并测试连接】，确认响应延迟和状态是否正常；  
3. 若使用第三方反代或自建网关，请在浏览器权限弹窗中确认允许访问该域名；  
4. 当网络超时或异常时，Glean 会自动降级为原生字幕与内置 4 万离线词库，不会卡死播放器。

---

### Q3：为什么夸克网盘有时抓不到字幕？
**答**：  
夸克网盘加载内嵌字幕可能存在异步延迟。Glean 拥有 MutationObserver 监听与 HTML5 原生 TextTrack 轮询兜底，通常播放开始 1~2 秒内即可捕获。如需使用自己的外挂字幕，同样支持本地拖入。

---

### Q4：支持 Firefox 或其他浏览器吗？
**答**：  
目前代码默认针对 Chrome Manifest V3（Chromium 内核，包括 Google Chrome、Edge、Brave、Arc 等）进行了最严格的端到端自动化测试与优化。Firefox 相关的打包脚本已内置（`bun run build:firefox`），后续将持续完善多浏览器适配。
