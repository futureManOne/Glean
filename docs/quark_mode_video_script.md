## 📋 五、录制实操检查清单（录制前务必核对）

- [ ] **准备测试文件**：在夸克网盘建一个测试文件夹，放入一段 1~2 分钟的英文视频（如《老友记》或 TED），并在同一文件夹内放入同名或带中英的 `.srt` / `.ass` 文件。
- [ ] **浏览器缩放**：按 `Cmd/Ctrl + 0` 恢复 100% 默认缩放，避免 UI 比例过大或过小。
- [ ] **全屏模式演练**：先测试一下点击右下角原生【拾句】开关、展开侧边栏、单句循环等操作，确保鼠标移动平滑。
- [ ] **麦克风降噪**：关闭空调和风扇，录音音量峰值保持在 `-6dB` 至 `-3dB` 之间。
