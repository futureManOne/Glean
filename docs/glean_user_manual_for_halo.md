## 💡 为什么需要 Glean (拾句)？

很多小伙伴在尝试**“看剧/看视频学英语”**时，往往陷入以下几个痛苦的死循环：
1. **界面臃肿，严重遮挡画面**：很多插件在视频中央挂着各种大黑条、工具栏，破坏观影沉浸感；
2. **生硬机翻，看懂了又好像没看懂**：直译机翻语法支离破碎，无法理解地道俚语和说话人真实语气；
3. **网盘资源无法使用**：绝大多数插件仅支持 YouTube，而我们在**夸克网盘**里囤积的大量生肉美剧、公开课根本无法享受双语辅助；
4. **频繁暂停查词，学习心流碎一地**：看到生词切出去开词典，查完就忘，无法沉淀到 Anki 中长期复习；
5. **付费订阅与隐私风险**：动辄几十元/月的昂贵订阅，且个人浏览数据与账号全被传回云端。

为了彻底解决以上所有痛点，**Glean（拾句）** 应运而生。它是一款**极致轻量、零画面遮挡、隐私优先**的 Chrome MV3 扩展，将普通的视频播放页瞬间升级为你的私人沉浸式外语教学现场！

## 🌟 核心功能一览

### 1. 🎬 沉浸式极简双语字幕与实时提词器
- **零干扰准则**：视频画面内部绝不渲染常驻的悬浮工具黑条，所有开关与设置无缝嵌入播放器底部的原生控制栏，随控制栏智能隐藏；
- **防脱手安全拖拽**：字幕条可任意上下拖动，拖动时自动激活全屏隔离遮罩，边界限制保护（3% ~ 80%），双击手柄瞬间复位（8%），并自动记忆你的位置偏好；
- **五态字幕循环（快捷键 <kbd>C</kbd>）**：`双语` ➔ `中英混合` ➔ `仅外语` ➔ `仅译文` ➔ `全隐藏` 自由切换；
- **听力磨砂遮罩**：支持将中文或英文进行虚化模糊处理，鼠标悬停才显形，强迫大脑先听后看！

### 3. 🧠 播放感知 AI 毫秒级精翻（Seek 抢占黑科技）
- 支持接入 **DeepSeek、Grok、OpenAI (GPT-4o/mini)、Google Gemini** 或任意自定义 OpenAI 兼容接口；
- **独创优先级队列 (`PriorityBatchQueue`)**：
  - 传统插件按顺序翻译整部视频，往往前面几十句翻完了，你看的地方还在排队；
  - Glean 具备**实时播放感知能力**，首个批次必定抢占翻译当前播放指针所在的句子；
  - 当你拖动进度条（快进/快退 Seek）时，调度器**立即打断后台并插队**，1 秒内将跳转位置的字幕替换为高质量 AI 精翻！

---

### 4. 📖 逐词即查词卡与 CEFR 难度分级
- **逐词可点**：基于现代浏览器原生 `Intl.Segmenter` 分词算法，字幕中的每一个单词都是独立按键，毫秒级响应；
- **CEFR 欧标难度着色**：自动识别 `A1` 到 `C2` 难度等级，生词一目了然；
- **内置离线词库**：集成 ECDICT 核心离线词典（**42,978** 条词条 + **94,108** 条词形还原），断网也能查；
- **ESL 深度教学卡片**：
  1. **解释卡**：音标、词性、柯林斯星级、当前语境真实含义与说话人意图；
  2. **例句卡**：原句语境 + AI 拓展 3 组精选例句，包含深入【词义用法解析】与【句法结构剖析】；
  3. **语法卡**：剖析该词在句子中的语法成分与固定搭配。

### 5. 📥 知识内化与复习闭环（一键导出 Anki）
- **口语跟读与循环**：
  - 按 <kbd>S</kbd> 瞬间从头重播当前句子；

  - **生词本导出**：一键导出 **Anki TSV 牌组**（直接导入手机或电脑 Anki）、CSV 词汇表。

## ⚡ 3 分钟快速安装指南

由于 Glean 是纯正的开源项目，无需通过 Chrome 应用商店审核等待，你可以直接通过开发者模式本地加载：

### 步骤 1：下载或构建扩展
从 GitHub 仓库下载最新的构建产物包，或在本地极速构建：
```bash
git clone https://github.com/futureManOne/Glean.git
cd Glean
bun install       # 或 npm install / pnpm install
bun run build     # 生产构建 Chrome MV3 产物
```
构建完成后，项目根目录下将生成 `.output/chrome-mv3` 文件夹。

### 步骤 2：加载到 Chrome / Edge 浏览器
1. 打开浏览器，访问扩展管理页面：
   - Chrome：在地址栏输入 `chrome://extensions/`
   - Edge：在地址栏输入 `edge://extensions/`
2. 打开右上角的 **【开发者模式】(Developer mode)** 开关；
3. 点击左上角的 **【加载已解压的扩展程序】(Load unpacked)**；
4. 选择本项目目录下的 `.output/chrome-mv3` 文件夹；
5. 安装完成！点击浏览器右上角拼图图标，将 **Glean (拾句)** 固定到工具栏。

## 🛠️ 配置 AI 大模型密钥（可选）

Glean 内置 4 万+ 离线词库，**不配置任何 Key 即可使用 90% 的查词与双语字幕功能**。若想开启全片 AI 精翻与 ESL 例句拆解：

1. 点击网页右侧台词栏右上角或控制栏的 **⚙️ 设置**；
2. 在 **AI 服务商** 下拉框中选择你的模型来源：
   - **Google Gemini**（推荐，默认免费额度充足）
   - **DeepSeek**（极高性价比，翻译极其地道）
   - **Grok** / **OpenAI (GPT-4o-mini)**
   - **自定义**：填入任意 OpenAI 兼容的 Base URL 与 Model 即可；
3. 填入你的 `API Key`，点击 **【保存并测试连接】**，系统会自动测速并拉取模型列表。

> 🔒 **安全承诺**：你的 API Key 仅保存在浏览器本地的 `chrome.storage.local` 中，直连模型官方接口，绝无任何中间服务器中转或收集！

## ❓ 常见问题排查 (FAQ)

**Q：遇到没有字幕的生肉视频怎么办？**  
A：Glean 贴心地提供了本地外挂字幕功能！点击侧边栏的【导入字幕】，将本地下载好的 `.srt` / `.vtt` / `.ass` / `.txt` 字幕文件拖入即可瞬间加载同步。

**Q：为什么有的视频 AI 翻译没有触发？**  
A：请首先在设置中确认 API Key 余额是否充足，并点击“测试连接”。若网络超时，Glean 会启动优雅降级，优先显示原生字幕与离线释义，绝不会导致页面卡死。

**Q：导出的 Anki 卡片如何导入手机？**  
A：在侧边栏导出 `.tsv` 格式文件，打开电脑端 Anki 点击“文件 -> 导入”，字段映射为【正面：英文原句 + 时间戳】、【背面：地道中文译文 + 语法解析】，同步至 AnkiWeb 即可在手机上随时随地复习！
