## 2. 录制前期筹备与环境清单

### 2.1 硬件与录制参数
- **视频画质**：1080P 60fps（码率 15Mbps 以上）或 4K 60fps。
- **音频采集**：电容麦克风或无线领夹麦，开启环境降噪，录音电平控制在 `-12dB ~ -6dB`，人声清晰饱满无爆音。
- **真人机位**：相机平视胸部以上，背景整洁带微弱氛围灯（如暖光台灯或科技蓝补光），打造真诚亲切的独立开发者形象。
- **录屏软件**：推荐 OBS Studio（录制无损 MKV/MP4），分辨率设为原生 1920×1080，缩放 100%（保证代码和字幕绝对清晰锐利）。
- **辅助工具**：
  - 键盘按键回显工具：推荐 **Keyviz**（开源免费，可在屏幕角落优雅显示 <kbd>C</kbd>、<kbd>V</kbd>、<kbd>S</kbd>、<kbd>Z</kbd> 等快捷键）。
  - 鼠标高亮工具：推荐 **Cursor Highlighter** 或录屏自带鼠标点击黄圈。

### 2.2 浏览器演示环境搭建
1. 使用全新的 Chrome/Edge 干净 Profile，关闭其他杂乱插件，隐藏书签栏（`Ctrl+Shift+B`）。
2. 将 Glean 插件通过 `加载已解压的扩展程序` 安装好。
3. 预先打开 3 个干净的标签页：
   - 标签页 1：YouTube 高清英文演讲/影视片段（如 Steve Jobs 斯坦福演讲或科技发布会）。
   - 标签页 2：B站高清双语/英文视频（如科技博主评测、TED演讲）。
   - 标签页 3：夸克网盘网页版（`pan.quark.cn`），存放一部带内嵌字幕或外挂字幕的英文电影/剧集。
4. 预先在设置中填入你的 AI Key（如 DeepSeek 或 OpenAI），并测试连接成功。

### 2.3 演示操作演练清单（录制前过一遍）
- [ ] 播放视频时，点击单词立即弹出词卡（展示离线释义 + CEFR 欧标等级颜色）。
- [ ] 按 <kbd>C</kbd> 键快速切换 5 态字幕（双语 ➔ 混配 ➔ 纯外语 ➔ 纯中文 ➔ 隐藏）。
- [ ] 按 <kbd>V</kbd> 键瞬间显隐全部字幕。
- [ ] 拖拽字幕条，展示边界保护与双击手柄复位。
- [ ] 按 <kbd>S</kbd> 键单句瞬间重播，按 <kbd>Z</kbd> 键开启单句无限循环。
- [ ] 点击右侧提词器任意句子，视频瞬间跳转。
- [ ] 断开电脑 WiFi，在离线状态下再次点击生词，秒出柯林斯星级与音标，展示离线词库威力。
- [ ] 点击「导出」，打开导出面板，展示全片双语剧本导出 Word/PDF，以及生词导出 Anki TSV。

## 4. Anki 闪卡与学习闭环深度解说指南（供口播备忘）

> **给 UP 主的专属说明**：  
> 鉴于你在采访中提到之前没有深度使用过 Anki，**千万不要有心理负担**！在视频里你不需要充当 Anki 专家去教用户复杂的 Anki 配置，只需要把它定位为**「Glean 生词本的高阶导出出口之一」**即可。以下是核心知识点速记：

### 4.1 什么是 Anki？为什么语言学习圈奉它为神？
1. **本质**：Anki 是一款开源的**智能记忆卡片（Flashcard）软件**（电脑、手机、网页都能用）。
2. **底层原理**：它内置了**艾宾浩斯遗忘曲线算法（SRS，间隔重复系统）**。你背一个生词，它今天考你一次，你记得住就 3 天后考你，记不住就明天再考你，科学帮你把短期记忆变成长期记忆。
3. **传统痛点**：学英语最痛苦的是**手动做卡片**——看视频抄生词、查音标、复制例句，做一张卡片要 3 分钟。
4. **Glean 的杀手锏解决方式**：
   - Glean 的生词本支持**「一键导出 Anki TSV 格式」**。
   - 文件内部已自动按制表符（Tab）排好序：`单词 | 音标 | 中文释义 | 原句英文 | 原句中文 | 掌握程度 | CEFR等级`。
   - 用户在 Anki 软件里点击「导入文件」，直接一秒生成上百张带例句和音标的专属影视记忆卡片！

### 4.2 口播时的避坑建议
- ✅ **推荐话术**：“无论你是用全球最流行的 Anki 闪卡科学背单词，还是喜欢导出 Word/PDF 打印复习，Glean 都帮你把生词导出的闭环做好了。”
- ❌ **避免话术**：“接下来我教大家怎么去 Anki 里面配置模板、设置记忆间隔……”（会导致视频节奏拖沓崩坏，非 Anki 用户会直接滑走）。

## 5. 后期剪辑包装与节奏把控指南

### 5.1 剪辑节奏与镜头剪接（Pacing & Cutting）
1. **黄金 5 秒黄金法则**：开篇第一秒直接抛出痛点，**严禁使用任何形式的长达 3 秒以上的冷场片头片花**。
2. **气口与停顿修剪（Breath Cut）**：口播录音中所有超过 0.4 秒的思考停顿、咽口水声、重复字句，全部用剪映/PR 的「消除无声片段」切干净，保持高密度、紧凑的知识输出感。
3. **动态缩放（Dynamic Zoom-in）**：录屏演示长达几分钟容易产生视觉疲劳。每当讲到具体功能（如点击查词、切换按键、导出面板）时，画面必须做 **1.2x ~ 1.4x 的平滑缓动放大（Slow Zoom-in）**，将视觉焦点死死锁在鼠标操作区域。

### 5.2 视觉特效与花字规范
- **快捷键浮现**：每当按下 <kbd>C</kbd>、<kbd>V</kbd>、<kbd>S</kbd>、<kbd>Z</kbd> 等快捷键时，屏幕中下方必须出现带有键盘质感的 3D 浮雕按键图标，伴随清脆打字声。
- **重点功能红圈/高亮遮罩**：当演示四层嗅探、离线词库或 AI 调度时，将背景压暗 30%，用聚光灯效果突出核心 UI，提升专业感。
- **色彩与字体推荐**：
  - 中文字体：推荐 `思源黑体 Heavy`、`OPPO Sans`、`方正粗雅宋`（大标题）。
  - 英文字体：推荐 `Inter`、`JetBrains Mono`（展示快捷键与代码）。
  - 花字配色：主色为 `#FACC15`（醒目暖黄）或 `#38BDF8`（科技天蓝），白色文字配合 `2~3px` 黑色描边与投影，保证在任何背景下都不融入背景。

### 5.3 BGM 选用清单与音量平衡
- **片头痛点段 (00:00 - 00:25)**：低悬念、带微弱时钟滴答或心跳律动的低音环境音，音量 `-24dB`。

- **片尾开源升华与求三连 (06:15 - 07:30)**：温暖、富有感染力、节奏明亮的轻摇滚或阳光木吉他，音量 `-18dB`。
- **关键音效（SFX）**：
  - 鼠标点击：清脆 "Pop" 或 "Bubble"（出现词卡时）。
